请帮我设计并实现一个“阀门交互式学习平台”的网页第一版。

这是一个面向机械、自动化、控制工程学生的教学型网页，目标不是做工业级仿真，而是通过清晰的二维剖视动画和实时交互，让用户直观理解：

“阀门结构 → 阀门开度 → 流通面积变化 → 流量变化”

请直接完成一个可以运行的前端项目，而不只是输出设计方案。

====================

项目名称暂定：

ValveLab
阀门交互式学习平台

- 工程感
- 科技感
- 简洁
- 专业

====================
五、阀门剖视动画
====================

必须画“内部剖视结构”。

尽量表现：

- 阀体
- 阀杆
- 阀芯 / 阀板 / 球体 / 闸板
- 阀座
- 管道
- 流体区域

根据不同阀门制作不同运动方式。

--------------------
球阀
--------------------

核心动画：

球体旋转。

开度 0%：
球体通孔与管道垂直。

开度 100%：
球体通孔与管道完全对齐。

开度变化：

0° → 90°

用户拖动开度时，球体连续旋转。

视觉上必须能够明显看到：
“球体内部的孔”和“管道”的相对位置。

--------------------
蝶阀
--------------------

核心动画：

蝶板绕中心轴旋转。

0%：
蝶板基本垂直于流向。

100%：
蝶板基本平行于流向。

动画应体现：

阀板角度变化
→ 流通区域逐渐增大

--------------------
闸阀
--------------------

核心动画：

闸板上下直线运动。

0%：
闸板完全落下，堵住流道。

100%：
闸板完全升起。

显示：
阀杆向上带动闸板。

--------------------
截止阀
--------------------

核心动画：

阀瓣上下运动。

重点显示：

阀瓣
阀座
弯曲流道

用户应该能看出：

即使阀门全开，
流体也需要改变流动方向。

这样可以帮助理解为什么截止阀流阻一般比闸阀更明显。

--------------------
调节阀
--------------------

采用典型直行程单座调节阀结构。

显示：

阀杆
阀芯
阀座
阀体
流道

阀杆上下运动时：

阀芯和阀座之间的节流面积连续变化。

这一种阀门的动画应该重点表现：

“连续调节”

而不是简单开关。

====================

使用：

流动。

流线更明显

开度较小：

粒子运动慢
数量减少

====================
九、不同阀门不要使用完全相同的流量关系
====================

这是教学重点。

请给不同阀门设计不同的“示意性开度—相对流量关系”。

不要全部使用：

Flow = Opening

例如可以表现：

闸阀：
前期流量变化相对明显，后期变化趋缓。

截止阀：
相对适合调节，变化较平滑。

调节阀：
采用类似线性特性。

蝶阀：
具有明显非线性。

球阀：
低开度阶段流量较小，中高开度变化较明显。

这些关系只用于教学演示。

请明确标注：

“曲线为简化教学模型，不代表具体工业阀门的精确流量特性。”

所有公式和函数集中放在：

valveModels.ts

或类似文件里。

不要散落在 UI 代码中。

方便以后替换成真实数学模型。

十一、结构说明
====================

例如球阀：

结构：
球体
阀杆
阀座
阀体

工作原理：

阀杆带动球体旋转，通过改变球体通孔与管道之间的相对位置控制流体通断和流通面积。

蝶阀：

蝶板绕阀轴旋转，通过改变蝶板与流向之间的夹角改变有效流通面积。

闸阀：

阀杆带动闸板上下移动，实现流道开启或关闭。

截止阀：

阀瓣沿阀杆方向移动，通过改变阀瓣与阀座之间的距离改变流通面积。

调节阀：

阀芯沿阀杆方向连续移动，通过改变阀芯与阀座之间的节流面积，实现连续流量调节。

文字保持简洁。
