# ValveLab V3.1 优化方向

日期：2026-09-07。状态：已按本方案实施并于 2026-09-08 完成联动验收。第 1～10 节保留原设计依据；实际实现说明见第 11 节，验证结果见 VALIDATION_v3.1.md。

依据：[阀门网站带教](thread://01a07ad4-6df7-7470-b607-6d0bd19f1e6d?hostId=local) 的实际提问、当前 V3 源码及既有页面验证截图。以下区分已经存在的行为与建议新增的能力，不把建议写成已实现功能。

## 1. 版本定位

V3.1 的重点是让学习者在同一视野内完成调参、观察、解释和对比。继续由 Simulink 唯一计算动态，网页承担参数、阀门反馈和学习提示；完整波形及数据分析继续在 MATLAB 中完成。

建议先完成参数布局、波形默认配置、信号解释及调参反馈，再增加实验课程和传感器参数。真实设备辨识和更复杂的物理模型放到后续版本。

## 2. 带教暴露的问题

| 带教中的实际问题 | 当前页面或模型情况 | V3.1 的对应改进 |
| --- | --- | --- |
| 如何在调节同时查看波形变化 | 参数分布在左侧、右侧和底部；需与 MATLAB 分屏 | 集中调参，优先设计 900～1100 px 浏览器窄窗 |
| 如何自动调整 X、Y 轴尺度 | 模型构建脚本仅明确打开 Scope 图例，没有提供统一的滚动时间窗配置 | MATLAB 波形预设，默认最近 20 s、Y 自动缩放 |
| p、i、d、command、opening 等分别是什么 | 中英文名称散落，控制链缺少可直接阅读的解释 | 设置与反馈分区，中文名＋信号名＋单位，固定闭环说明 |
| measuredFlow 为什么落后 trueFlow；没有误差为什么还需要两者 | 传感器时间常数 0.2 s 写在 MATLAB 方程中，页面缺少专门说明 | 传感器知识卡与可重复的时间常数对照实验 |
| 0.05 s 是不是确定值，采样点怎样影响响应 | 仿真步长、网页刷新、传感器时间常数属于不同机制 | 分清仿真时间、采样周期、响应时间常数和通信新鲜度 |
| 故障注入用来做什么 | 可以注入，但学习者需要自行推断该观察哪几路信号 | 故障目标、观察对象、预期现象和恢复步骤 |
| 为何出现指数、为何是 63.2%、如何用实物数据拟合 | 这些内容超出当前按钮和读数能表达的范围 | 分层原理说明，MATLAB 中展示响应和辨识边界 |

## 3. 第一优先：集中参数，适配边调边看

### 推荐布局

采用顶部固定操作栏和两个主要区域。阀门选择从左侧五张大卡片改为参数面板顶部的紧凑选择器，结构展示旁显示当前阀门名称。

```text
┌──────────────────────────────────────────────────────┐
│ 连接状态  开始/暂停  单步  波形  保存本次  新实验      │
├─────────────────┬────────────────────────────────────┤
│ 统一参数面板    │ 当前反馈                            │
│ 阀门选择        │ SP / PV / Q · 命令 / 实际阀位       │
│ 手动 / PID      ├────────────────────────────────────┤
│ 目标数值＋滑杆  │                                    │
│                 │ 阀门结构与执行机构反馈              │
│ 控制 驱动 压力  │                                    │
│ 测量 故障       ├────────────────────────────────────┤
│ 当前分组参数    │ 当前实验：操作 → 观察 → 解释         │
├─────────────────┴────────────────────────────────────┤
│ 当前配置摘要：调节阀 · 电动 · Δp 1 bar · 无故障       │
└──────────────────────────────────────────────────────┘
```

- 常用操作固定在顶部，不因滚动或打开帮助而消失。
- 统一参数面板在宽窗约 320 px，在分屏窄窗约 280 px；高频的阀门、模式、目标始终可见。
- 其余参数使用控制、驱动、压力、测量、故障五个分组，每次显示一组。测量参数是拟新增功能，当前 V3 没有此分组。
- 每个参数只有一个编辑入口。重复显示只作只读摘要，避免两处编辑不同步。
- 参数区可局部滚动；阀门和关键反馈保留在视野内。原理、事件、导出详情按需展开。
- 分组切换不改变模型状态；当前故障、执行机构和压差始终在摘要栏可见，避免参数收起后遗忘工况。
- 高度不足的窄窗使用阀门/调参页签，保留运行栏和关键读数，不再把全部卡片依次堆成数屏长页。

核心验收：在 960 × 800 和 1366 × 768 视口，修改 SP、压力或执行机构参数时，不需要滚动整页才能重新看到阀位、PV 和暂停按钮。960 px 场景用于电脑上与 MATLAB 分屏，不能据此宣称支持实体手机跨设备连接。

## 4. 波形默认就能看清

当前打开 Scope 会打开三扇窗口。建议改成一个波形入口，优先显示当前实验需要的信号，另可切换流量、阀位、PID 视图。

建议提供两类 MATLAB 波形预设：

| 用途 | X 轴 | Y 轴与信号 |
| --- | --- | --- |
| 实时调参 | 默认最近 20 s，可选 5 / 10 / 20 / 60 s；持续滚动 | 自动适配可见数据，允许收缩；SP/Q/PV 或命令/阀位 |
| 暂停分析 | 本次全程或游标选段 | 可锁定轴范围，用于比较调参前后幅值 |

PID 的 P/I/D 量级差别可能很大，默认分三行并共享时间轴，避免较大的 I 项掩盖 D 项；保留叠加选项。若各行独立缩放，必须明确显示单位与轴范围，避免误读相对幅度。

网页增加恢复默认波形视图操作。Scope 与网页使用一致的名称、颜色和线型；颜色之外还用实线/虚线及明确图例区分目标与反馈。SDI 进入实验时自动选择本次运行对应的信号组合，不清除其他运行记录。

Scope 官方支持时间窗、坐标缩放和多 Scope 窗口管理，SDI 支持程序化设置子图与选取信号。具体属性和窗口组织方式须在 R2025b 实测后确定；这些显示设置不改变仿真步长。[Scope 文档](https://www.mathworks.com/help/simulink/slref/scope.html)、[Scope 配置接口](https://www.mathworks.com/help/simulink/slref/spbscopes.scope.timescopeconfiguration.htm)、[SDI 子图布局](https://www.mathworks.com/help/simulink/slref/simulink.sdi.setsubplotlayout.html)。

## 5. 把设置、反馈和原理分清楚

建议固定一条可点开的闭环说明：

```text
目标流量 SP → PID → 阀位命令 u → 执行机构 → 实际阀位 x
                                                  ↓
PID ← 测量流量 PV ← 传感器 ← 模型真实流量 Q ← 阀门与压差
```

| 显示名称 | 数据字段 | 页面定位 |
| --- | --- | --- |
| 目标流量 SP | setpoint | 自动模式的可调目标，L/min |
| 阀位命令 u | command | 控制器或手动指令输出，% |
| 实际阀位 x | opening | Simulink 执行机构反馈，% |
| 模型真实流量 Q | trueFlow | 模型过程量，L/min |
| 测量流量 PV | measuredFlow | PID 实际使用的测量反馈，L/min |
| P / I / D 贡献 | p / i / d | 对阀位命令的贡献，%；与 Kp/Ki/Kd 增益区分 |

设置和反馈采用不同的外观；目标不能呈现得像已经实现的结果。手动模式下明确 SP 不参与控制。增加三组差值的中文解释：控制误差 SP−PV、阀位跟踪差 u−x、测量与过程差 PV−Q；不把它们统称为传感器误差。

每个信号帮助分两层：先显示一句话和一个例子，再展开方程。解释稳态时 I 项可能非零、D 作用于测量值且有滤波、命令受 0～100% 限制。主工作区保持简洁，不把整段推导塞在阀门下面。

## 6. 调参反馈与实验记录

代码评估发现，目前 `pending` 会禁用整个参数区及顶部运行按钮；一个参数待确认时，其他编辑也被锁住。PID 数字输入还会在输入过程逐次提交，删除数字时可能暂时形成 0。因此应优先改善交互，而不仅是移动控件。

- 手动命令与 SP 保留实时调节，加入精确数字输入与阶跃按钮；滑杆拖动过程中仍能编辑和看反馈。
- Kp/Ki/Kd 等数字先作为草稿输入，完成输入或点击应用后校验并提交；空白和未完成的小数不提交，组合修改一次生效。
- 区分待发送、MATLAB 已接受、已进入仿真采样三种状态。参数接受不等于新阀位已经产生，尤其在暂停时。
- MATLAB 协议增加实际生效版本和仿真时刻；不能只把已有 `revision` 换一个中文标签就宣称可跟踪生效。
- 暂停入口始终可触达；如果 MATLAB 正忙，明确显示暂停请求待处理，不提前把网页标成已暂停。
- 事件记录改为目标流量 60 → 75 L/min 等有语义的变更，而非仅列 `setpoint` 字段名。分别保留接受时刻与实际生效时刻。
- 在 MATLAB 波形中显示阶跃、压力变化和故障事件位置；对照实验按同一仿真时刻执行，减少手动点击时机不同带来的干扰。
- 支持命名本次实验、保存配置快照和 MATLAB 运行对比。新实验、恢复参数、清除故障各自明确含义，避免重置按钮承担多种含糊操作。开始新实验前保留本次记录或提示保存。

## 7. 把带教内容变为可重复实验

建议增加自由实验 / 引导实验，使用同一套控件与 MATLAB 模型。引导实验只给出当前目标、推荐操作、观察信号和一个思考题，进阶公式按需展开。

| 实验 | 操作与观察 | 学习目标 |
| --- | --- | --- |
| 命令与实际阀位 | 手动 30% → 70%；观察 u 与 x | 执行机构速度限制和渐近跟随 |
| PID 跟踪 | SP 60 → 75 L/min；观察 SP/PV/Q 与 u/x | PID 通过阀位间接控制流量 |
| 压差扰动 | 在相同目标下改变入口压力 | 区分控制目标、外界扰动和容量上限 |
| 传感器响应 | 对比不同传感器时间常数下 Q 与 PV | 动态滞后与固定延时的区别 |
| 故障与恢复 | 稳定后注入一种故障，再清除 | 找到异常首先发生在哪个环节 |
| 一阶响应原理 | MATLAB 中展示独立传感器阶跃及 1τ/3τ 标记 | 63.2% 来自 1−exp(−1)；理解指数逼近 |

传感器实验需要把当前固定的 0.2 s 参数化，建议初期仅提供 0.05 / 0.1 / 0.2 / 0.5 / 1 s 五档。默认值保持 0.2 s，不改变既有基准结果。固定仿真步长 0.05 s 在 V3.1 作为只读信息；自由修改步长涉及求解、日志和全部动态环节，不应只加网页滑杆。

一阶阶跃课必须明确：63.2% 结论针对恒定阶跃输入的一阶响应。主回路还含执行机构速度限制、PID 和测量动态，不能把任意主回路流量曲线的 63.2% 到达时刻直接解释成传感器时间常数。独立传感器教学实验也应由 MATLAB 计算，网页不新增另一套求解器。

每张故障卡增加观察提示：卡死看 u/x 分离；气动失气看实际阀位返回方向；泄漏看关闭后 Q 是否仍非零；传感器偏差看 PV 接近 SP 时 Q 是否仍偏离。现有模型已知注入的故障并冻结部分积分，这是教学机制，不应包装为工业故障自动诊断。

## 8. 时间、连接和启动体验

带教中多次把采样周期与滞后联系起来。建议在测量帮助内明确区分：

| 概念 | 当前 V3 值或行为 | 应如何显示 |
| --- | --- | --- |
| 仿真步长 | 0.05 s，即仿真时间中的 20 Hz | 模型信息，只读 |
| 传感器时间常数 | 0.2 s，一阶渐近响应 | 测量组说明；拟开放调整 |
| 执行机构时间常数 | 默认电动 0.8 s、气动 0.35 s，另有速度限制 | 驱动组参数 |
| 网页状态轮询 | 请求周期约 250 ms，实际间隔受通信和排队影响 | 用最近反馈年龄表达，不称为仿真采样率 |
| 控制端心跳 | 每秒发送；超过 3 s 丢失则暂停 | 连接保护，与物理时间常数区分 |

连接状态拆成桥接可用、MATLAB 就绪、控制权、运行/暂停；提示具体下一步。将 `Failed to fetch` 改为中文可操作说明，原始错误折叠在详情。

启动页默认只展示统一启动脚本的复制按钮和启动进度，手动启动各服务放入高级说明。启动脚本应检查服务协议与模型就绪，而非仅凭端口被占用就认为启动成功。普通用户不需要把 Markdown、日志标记或 MATLAB 命令混着复制到 PowerShell。

切换焦点到 MATLAB 不应被解释为必然断连；真正的判据是心跳是否持续。需要实测分屏、切换窗口和浏览器节流下的行为，在保证真实失联会暂停的前提下减少误报。不能简单取消心跳保护。

## 9. 暂缓的方向

- 实测数据辨识：带教已涉及 command→opening、opening→参考流量、参考流量→测量流量三段辨识，值得后续单独开发。V3.1 先标明教学参数来源并保留导出信息，不提供未经验证的一键识别时间常数。
- 当前流量过程为准稳态关系，没有独立管路时间常数；不能在没有增加过程动态的情况下展示该参数的拟合结果。
- 参数单位、同步时间基准、参考仪表动态、速率限制和独立验证数据须先定义，再引入辨识工具。
- 随机噪声、可变步长、复杂 Simscape 模型、实体硬件接入和在线 AI 问答均不作为 V3.1 主线。

## 10. 建议优先级与验收

| 优先级 | 改动 | 验收重点 |
| --- | --- | --- |
| P0 | 两区域布局、参数集中、固定操作和反馈 | 在分屏窄窗内完成调参且不丢失阀位和暂停入口 |
| P0 | MATLAB 波形预设、默认信号分组 | 打开即可看到最近一段波形，初始大峰值移出后 Y 轴可收缩 |
| P0 | 信号词汇、设置/反馈区分 | 学习者可指出 PID 比较的是 SP 与 PV，输出为 u |
| P0 | 草稿输入、确认/生效状态、可触达暂停 | 修改数字不产生无意中间值，暂停调参不伪造新反馈 |
| P0 | 启动指引、服务诊断、连接状态 | 不看 README 全文也能明确下一步；真实断连保持停算 |
| P1 | 引导实验、传感器时间常数、分层原理 | 可复现 τ 对照，并解释 0.05 s 与 0.2 s 的不同含义 |
| P1 | 命名运行、参数快照、事件对齐、MATLAB 对比 | 同一激励下对比两组参数，重置前的实验可找回 |
| 后续 | 实测辨识与更完整物理模型 | 独立的数据、模型与验证方案 |

实施时先用布局和波形配置验证一条完整任务：连接 → 设定手动阶跃 → 边调边看 → 暂停 → 保存；通过后再加入 PID、传感器和故障课程。默认模型的数值迁移基准、0.05 s 单步、MAT/CSV 一致性及断连暂停须继续通过。新增的生效版本、传感器参数和实验调度需要在 MATLAB 与网页两端共同验证。

## 11. 实施说明

### 页面与实验

- 已实现固定运行栏、顶部五个关键反馈、统一参数面板和阀门观察区。在 960 × 800、1366 × 768 视口，五个参数分组均不需要整页滚动就能同时看到阀门、反馈和暂停入口；窄屏使用阀门/调参页签。
- 实现数字草稿校验、PID 组合应用、原位撤销、参数提交期间继续编辑和排队暂停。对话框内保留暂停入口。
- 增加六个学习实验、信号帮助、五档传感器时间常数、固定仿真时刻的阶跃与故障事件。切回自由实验会取消剩余调度；选择参数分组不改变模型。
- 阀门几何、运动和流线仍基于返回的真实采样。实际阀位、命令与参数设置分开显示，故障和压差始终保留在设置摘要中。

### MATLAB 与协议

- 新模型为 `matlab/valvelab_v31.slx`，使用独立的 V3.1 方程与 S-function 文件；原 V3 模型和方程保留作对比。默认 0.2 s 传感器响应与 V3 一致。
- V3.1 MATLAB 端口为 8776，网页和 HTTP 桥接仍为 5173 / 8765。原 V3 的 8766 会话可共存。启动脚本检查网页版本、桥接协议和模型就绪，不以占用端口作为成功标志。
- 模型输出增加 `appliedRevision`，共 20 列记录；服务另返回已生效的完整配置、应用时刻和会话标识。接受但在采样前被后续配置取代的版本，明确标记为 superseded。
- 保存目录为 `matlab/runs/v3.1`，包含 MAT 配置快照、课程、事件和 CSV 采样。重置、切阀、准备新课程会先保存已有采样或参数变更，保存失败不会继续重置。
- 中文实验名称的输入和输出均显式使用 UTF-8。文件名仅由时间戳与序号产生，名称作为元数据保存。
- 切回自由实验会在本页持有控制权时始终发送幂等的课程取消命令，不依赖可能稍旧的页面快照，确保剩余调度清零。

### R2025b 波形实现选择

- 使用一个网页入口选择流量、阀位或 PID 原生 Scope，每次只显示一个所选 Scope。PID 可三行或同轴叠加，支持实时、全程、选段和锁定 Y 轴。
- R2025b 的公开配置对象提供 `YLimits`，但未提供独立的允许收缩属性。本版由 MATLAB 服务按可见采样计算轴范围，每 5 个模型采样更新一次；仍使用 Scope 原生绘制，不增加另一套动态求解器。原生 `AxesScaling=Manual` 表示轴范围由服务维护；网页选择锁定后停止更新。
- 正在记录的 SDI 信号保留原生字段名和样式，只设置选中信号及子图布局。记录对比导入两份实际采样快照后统一名称、颜色、单位和线型；不修改正在记录的模型信号，也不删除其他 SDI 运行。Scope 保留原生配色，以字段名、标题、图例和单位为识别依据。
- MATLAB 全程分析图提供实际生效时刻的事件标记；暂停选段使用原生缩放与游标。独立传感器图标出 1τ 与 3τ。为了在单步 Simulink 会话中稳定打开图形，分析与传感器窗口在服务启动时预先创建并重复使用。
- 实测数据辨识、复杂管路、噪声、硬件接入和变步长继续属于后续范围。

### 启动与最终验收

- MATLAB 专用服务改用 `-nodesktop -nosplash`，避免完整桌面在后台启动时弹出“是否恢复自动保存/上次会话”的恢复窗口。该模式已验证 Scope、流式 SDI、Simulink 模型、分析图、传感器图和保存记录对比。
- 统一启动脚本对网页增加 12 秒就绪等待；失败时返回本次 `web-v31-*.error.log` 路径和最后连接问题。重复运行会核对 5173、8765、8776 的网页版本、协议和模型，不重置实验。
- 最终通过 39 项真实浏览器检查、169 项 MATLAB 检查、12 个对等场景共 24,282 个 Simulink 步，以及生产构建。详细证据与验证边界见 `VALIDATION_v3.1.md`。
