# ValveLab v1：阀门交互式学习平台

状态：第一版已按本文实现并完成验证。产品名为 ValveLab，本文按要求命名为 ValvesLab_v1.md。

## 1. 目标与交付范围

面向机械、自动化和控制工程学生，建立一条可观察的学习链：阀门结构 → 开度 → 相对流通面积 → 相对流量。打开页面即可选择阀门和调整开度，不设置登录或引导门槛。

交付位置为 `ValvesLab`，包含完整 React + TypeScript + Vite 前端、README、集中式教学模型、验证脚本及构建结果。通过 `npm install`、`npm run dev` 启动；`npm run build` 输出静态网站。沿用用户的本地前端交付范围，不增加外部托管、Git 写操作、服务器、数据库或网络数据依赖。保留原始要求和现有 Simscape 文件。

## 2. 案例分析与采用原则

### 2.1 本地 MathWorks Hydraulic Lift Table 案例

已阅读 `../Simscape-Hydraulic-Lift-25.1.3.6/README.md`、Overview 中的模型介绍，以及自定义液压节流元件。

- 案例通过控制阀芯位移改变液压流量，再改变执行器运动，体现输入、结构状态和输出结果之间的关联。第一版借鉴这种联动教学方式。
- 自定义元件 `CustomOrifice_coeff.ssc` 使用压降与流量的一次及二次关系，`CustomOrifice_full.ssc` 区分层流和湍流。它们属于带压力、介质等条件的物理模型，本项目不能直接把其系数移植为归一化开度曲线。
- 可借鉴模块化组织：阀门图形、参数、计算和说明相互分离。电机、PI 控制、液压缸与硬件在环内容超出本版范围。
- 不复用或修改 MathWorks 模型与图片；本项目重新绘制教学 SVG 剖视图。

### 2.2 阀门教材与制造商资料

- [Spirax Sarco：Control valves](https://www.spiraxsarco.com/learn-about-steam/control-hardware-electric-pneumatic-actuation/control-valves)：核对旋转阀和直行程阀的结构与运动关系，借鉴结构剖视加简短解释的教材方式。
- [Emerson：Control Valve Handbook](https://www.emerson.com/is/content/emerson/es/final-control/isolation-valves/documents/control-valve-handbook-en-3661206.pdf)：在恒定阀压差下讨论固有流量特性；实际安装特性还受系统条件影响。因此本版必须标明曲线是自定义教学模型，而非制造商曲线。
- [Valmet：Control valve installed performance](https://www.valmet.com/flowcontrol/valves/flow-control-manual/control-valve-installed-performance/)：补充理解固有特性与安装特性之间的区别，不能从开度单独推算现场真实流量。

检索日期：2026-09-05。上述资料支持结构原理与模型边界，下文具体公式为本项目自定义，并非从手册拟合。

### 2.3 初稿需澄清的教学细节

1. 五种阀门并不对应五种完全不同的运动学：球阀、蝶阀均为旋转，闸阀、截止阀及本版调节阀均为直线升降。验收应检查五种内部结构与运动对象可辨识，不能虚构不同运动自由度。
2. 球阀使用垂直阀杆轴线的流道平面剖视，明确标注观察方向；球孔在该平面旋转。蝶阀采用经过流向的剖视，蝶板转角以关闭位置为零。避免把球体画成平移或把蝶板画成升降。
3. 截止阀与调节阀采用折弯流道。截止阀为较宽的阀瓣，调节阀为带轮廓的阀芯，突出升程改变节流间隙。本版直行程调节阀仅代表一种结构，调节阀不是与截止阀互斥的全部机械分类。
4. 相对面积与相对流量分别按各阀全开值归一化。五种阀全开均显示 100%，不能用于比较绝对通流能力或压降大小。
5. 粒子速度代表整体流动强弱，不代表局部真实速度；不能由动画推断狭缝中的流速或涡流。
6. 闸阀显示前快后缓的教学曲线，但说明它主要用于截断，不据此推荐长期节流。

## 3. 页面与视觉

采用深蓝灰工程实验台：低亮度网格画布、金属灰阀体、橙色运动件、青色流体及曲线。以剖视图为视觉中心，不做营销首屏。

桌面布局：

- 顶部：ValveLab、中文名称、简洁学习副标题、版本标识。
- 左侧：五种阀门列表，含结构图标、中英文名称、用途标签、当前选中状态。
- 中间：大型 SVG 剖视、视图类型、流动方向、少量零件引线、图例与简短结构说明。
- 右侧：开度数字、连续滑杆、0/25/50/75/100% 快捷按钮、当前阀门、角度或归一化升程、面积与流量。
- 下方：开度—相对流量曲线和工作点；用途、运动方式、调节能力及特点；核心教学提示。

桌面 1440px 左右采用三栏；平板改为顶部阀门选择加两栏；手机采用横向阀门列表与单栏，控件适合触摸，剖视图保持完整。避免水平整页溢出。中文为主，英文用于术语和辅助标识。

| --- | --- | --- | --- | --- |

| 蝶阀 Butterfly Valve | 短阀体、阀座、蝶板、中心阀轴 | 蝶板横挡流道 | 蝶板沿流向 | 全开仍存在阀板和轴 |
| 闸阀 Gate Valve | 阀体、阀座、闸板、阀杆 | 闸板落下封住流道 | 闸板提升至流道上方 | 直通、主要用于截断 |
| 截止阀 Globe Valve | 阀瓣、阀座、阀杆、折弯流道 | 阀瓣压住阀座 | 阀瓣离座 | 全开仍需转向 |

SVG 尺寸为教学示意，不作为工程尺寸；每个阀门独立组件。运动件使用 SVG transform，流体由 SVG 路径与粒子绘制，流体层限制在可见流道内，关闭时不生成通过阀门的流线和粒子。剖视图明确流向从左到右。

## 5. 集中式教学模型

唯一开度状态 `opening`，范围为 0～100，滑杆步进 0.1。设 `h = opening / 100`，`theta = pi*h/2`，面积 `a` 与流量 `q` 范围均为 0～1。

| 阀门 | 相对面积 a | 相对流量 q | 特征 |
| --- | --- | --- | --- |
| 球阀 | sin(theta)^2 | a^1.2 | 低开度流量小，中段变化更明显 |
| 蝶阀 | 1-cos(theta) | a^1.1 | 明显非线性 |
| 闸阀 | h | 1-(1-h)^2 | 前段快、后段缓 |
| 截止阀 | h | 1.3h/(1+0.3h) | 平滑、温和非线性 |
| 调节阀 | h | h | 本例采用线性阀芯教学特性 |

模型在 `src/models/valveModels.ts` 集中定义，包含开度约束、面积、流量、角度/升程、曲线采样。参数、曲线、粒子强度均调用同一模型输出。禁止 UI 另行计算流量。输入非有限数时明确抛错，不静默使用默认值；有限越界值约束到边界。

转动件显示相对关闭位置的转角 `90h` 度；升降件显示归一化升程 `100h`%，不编造真实毫米行程。几何 transform 与模型状态对应，图形路径计算集中在阀门几何层。

必须满足：端点准确，0% 时 a=q=0，100% 时 a=q=1；全区间有限、单调、无跳变；五条曲线不同。归一化数值不能被解读成工业选型数据。

## 6. 交互

1. 默认选择球阀、65% 开度，首屏即有结构和流动可观察。
2. 切换阀门保留开度，说明、结构、参数和曲线同步切换，不刷新页面。
3. 滑杆拖动实时改变同一个状态；所有读数与图形使用同一帧状态，避免各自缓动导致不同步。
4. 快捷按钮支持 0/25/50/75/100%；滑杆支持方向键、Home、End。
5. 提供流动动画播放/暂停以及标注显示/隐藏，暂停只冻结粒子，不影响开度和模型结果。
6. 鼠标悬停、键盘聚焦或触摸点击零件时高亮并显示中英文名称及一句解释；切换阀门清除旧零件状态。
7. 曲线使用 SVG，包含轴标题、0/25/50/75/100 刻度、当前点与投影辅助线。工作点与参数一致。
8. 尊重系统减少动画偏好：初始停止粒子运动，手动调整开度、读数和曲线仍正常工作。

## 7. 界面固定提示

- 阀门开度并不一定与流量成线性关系。
- 实际流量还会受到阀门结构、压差、介质性质和流量系数等因素影响。
- 流体动画为概念性示意，并非 CFD 数值仿真。
- 曲线为简化教学模型，不代表具体工业阀门的精确流量特性。
- 各阀按自身全开值归一化，不用于比较绝对流量。
