## MATLAB 数值与模型验证

执行：

```powershell
matlab -batch "addpath('matlab'); verify_valvelab_v31"
```

覆盖内容：

- 五种阀门与电动、气动两种机构的 Simulink / 独立方程逐步对等。
- 手动与 PID 模式、执行机构一阶响应及速率限制、饱和恢复和无扰切换。
- 压差容量、卡死、能源中断、阀座泄漏、传感器偏差和传感器时间常数。
- 接受版本、实际生效版本、生效时刻，以及采样前被后续配置取代的版本。
- 命令与阀位、PID 跟踪、压差扰动、传感器响应、卡死与恢复五个定时课程。
- 20 列实际信号、MAT/CSV 一致性、配置快照、课程、事件和 UTF-8 实验名称。
- Scope 时间窗、自动 Y 轴、锁定 Y 轴、PID 分行/叠加，以及非法波形参数拒绝。

12 个对等场景累计 24,282 个固定步长采样，最大绝对误差为 (5.3148596634855494\times10^{-12})。固定步长仍为 0.05 s；默认传感器时间常数仍为 0.2 s，因此 V3 的默认数值基准得到保留。

## 启动故障复现与修正

一次失败现场中仅 8765 桥接处于监听，5173 网页和 8776 MATLAB 服务均未启动。`web-v31-20260908-024948-222.error.log` 显示当时宿主处于受限执行环境，Vite 创建子进程被操作系统以 `spawn EPERM` 拒绝；因此浏览器无法连接不是网页业务代码或 MATLAB 模型错误。

最终处理：

- 恢复允许本地子进程的正常运行环境后重新执行统一启动，网页、桥接和 MATLAB 全部就绪。
- MATLAB 服务改用 `-nodesktop -nosplash`，避免完整桌面恢复自动保存/上次会话的弹窗挡住后台启动。
- 网页服务由单次请求改为最长 12 秒的就绪等待；失败时报告本次 `web-v31-*.error.log` 路径和最后连接问题。
- 重复执行统一启动脚本已验证不会重复启动现有服务，也不会重置运行。

最终健康状态：网页 HTTP 200，页面版本 3.1；桥接协议 31；MATLAB R2025b；模型 `valvelab_v31`；初始为暂停且无控制端。

## 验证边界

- 浏览器验证覆盖 Chromium 桌面和模拟窄屏；未执行实体手机、Safari、Firefox 或完整 WCAG 审计。
- 阀门几何和流体动画是教学示意，不是 CAD、CFD 或工业选型计算。
- 模型采用固定水样介质、正向准稳态压差，没有反向流动、气蚀和独立管路动力学。
- 未连接实体阀门、PLC 或硬实时系统；“实际阀位”始终指 Simulink 执行机构输出。
- 启动脚本依赖 Windows、PowerShell 7、Node.js 22.12+、MATLAB R2025b、Simulink 和 Instrument Control Toolbox。
